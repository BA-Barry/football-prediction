## 赛事重视程度的处理边界

先记录可观测事实：当时的积分／晋级状态、前后赛程、休息小时、旅行、球员近期分钟、轮换迹象与有来源的表态。缺失信息保留未知；今天获得的历史消息不冒充当时已知。

当前 `MatchContext` 本身不改进球率。情景中的人员变化已通过阵容输入计入时，不再追加一次“轮换／战意扣分”。只有历史训练与时间外验证支持的额外战术／优先级效应，才考虑进入正式预测。正式训练适配器和这些系数尚未实现。

`lineup_confirmed` 版本要求本场双方官方公告及其观测时间，并使用有首个在场 XI 的预计时段情景；只有平均分钟不足以确认谁首发。后续时段仍是假设，不知道实际换人。当前只有主动触发的少量公开赛果下载，没有定时运行、实时首发抓取或历史快照数据库。

情景权重记录来源和可用时间；缺少时间时明确无法核验。即使给出时间戳，也不能代替真实的数据来源记录。`compare_versions()` 要求两份预测的比赛、双方球队、赛事、目标开球时间等一致；改期应单独说明，不能直接当成同一信息更新。

## 两个模块之间尚不能直接拼接

`TeamGoalModel.predict()` 输出的是球队**边际平均**进球率（`team_marginal`）。阵容修正需要经拟合校准的**条件参考阵容**进球率（`conditional_reference`）。

只减去平均分钟并不够：由于指数非线性，`E[exp(delta)]` 一般不等于 1。把边际进球率直接当条件进球率，会造成均值漂移。当前赛前接口会指出该语义不匹配；v0.7.0已在独立历史模型中联合拟合球队／球员，不以旧边际强度作为offset。它与赛前情景、未知阵容路径的衔接仍未实现，不能用修改字段标签来代替拟合。

同样，球队模型输出的 `reference_match_ids`、`reference_weights` 仍需由数据适配器用于构造同窗口参考阵容。仅有一个较早时间戳，并不能证明它的数据来源没有泄漏。

## 首轮日期级实验的解释边界

- 时间范围：原始数据2024-08-15至2025-05-25；检验期2025-01-01至2025-05-25。五个联赛各自的训练/检验数量在报告中列出。
- 固定沿用正则0.01、时间半衰期180天、rho=0，不按本轮检验成绩挑参数。每次更新的训练日期严格早于本周起点；同周结果不倒灌，但下周可以使用上周已结束结果。
- 市场只作双轨对照，不参与球队拟合。pre-closing不是已核实的开盘，closing不是赛前24小时；没有报价时间就不构造OddsSnapshot。
- 特殊裁决比赛柏林联合—波鸿不作为场上进球学习；完整原始比分仍留在CSV。其他有效高比分比赛不因离群而删除。
- Poisson计数诊断包括原始分布、预测/实际进球均值、Pearson残差和双方残差相关；这些是描述性检查，不证明独立性或Poisson假设成立。不套用OLS正态残差检查。
- 与市场的配对Log loss差异按更新周重采样，固定种子，报告探索性95%区间，不是参数区间，也不能消除全部球队/时间依赖。
- 赛季末参数保存为可读JSON，训练仅止于2025年，不代表2026年当前实力；目前不能外推欧战、阵容或半全场。后续调参必须另留较晚时段/赛季检验。

## 精确时点与球员训练仍需的数据工作

数据适配器应分别记录事实发生时间、来源观测时间、预测时间，而非将今天爬到的历史网页假装成当时就知道的信息：

1. 比赛：稳定赛事、球队、赛季和比赛 ID；真实开球时间、90 分钟比分及结果可获知时间；加时赛与点球分开。
2. 球队历史：只向过去滚动的射门／xG／进失球和对手强度；训练窗口和时间权重与参考阵容一致。
3. 球员：稳定球员 ID、角色、历史在场时段、换人、红牌、当时比分及 xG／进球；替补能力与门将信息分开研究。
4. 赛前阵容：预计／确认状态、消息来源和观测时间、若干相互一致的阵容／换人路径；目标比赛实际换人不能用于赛前输入。
5. 赔率：公司、玩法、盘口线、时间、价格与结算规则。历史 CSV 的 pre-closing 不等于开盘；不能用收盘数据假装赛前 24 小时可用。

## GAP独立胜平负研究（2026-10-25）

`gap_model.GAPState`维护进球、射正、非射正射门和角球的主客攻防状态，`gap_outcome.GAPOutcomeModel`直接复用statsmodels有序logit输出主胜／平局／客胜。`work/run_gap_20261025.py`从较早历史学习参数并按原发布日期前推，模型可保存、加载；`work/evaluate_gap_20261025.py`与旧路线逐场配对。只用本地历史文件，不自行联网或结算当前赛果。

本轮已完成22次映射训练和3,452场研究预测，两个后季均未超过较强既有统计线，故未替换。结论与复用模型在G盘`outputs/GAP胜平负研究_20261025/`。它只产生胜平负概率，不能代替比分、总球或让球模型；历史日期口径也不是重建精确的赛前72小时。

## 历史代表性与证据联合（2026-10-25）

`historical_relevance.personnel_usage_overlap()`只使用截止日前已观察的首发身份，比较互不重叠的近5场和前15场人员使用份额。它不需要目标首发，不把份额当作球员能力、分钟或转会名单；不足窗口返回未知。真实760场历史已接入377场旧预测作描述测量，没有发现可直接套用的“连续性高就提高信心”规则。

`evidence_reconciliation.reconcile_evidence()`保留原统计和独立LLM概率，以有来源的新模型知情评论解释分歧、重复信息与历史迁移缺口。它不平均概率，不把共同首选提升为联合置信度。十场原赛前记录的执行脚本为`work/run_evidence_reconciliation_20261025.py`，真实历史测量为`work/measure_history_relevance_20261025.py`；产物在G盘`outputs/历史代表性与证据联合_20261025/`。当前跨季人员映射不足时明确留空，旧历史指标不能外推成当前阵容连续性。它是可运行的研究解释层，尚不是已训练的人员概率修正。

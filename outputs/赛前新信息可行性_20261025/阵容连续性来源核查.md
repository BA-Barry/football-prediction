## 1. dcaribou/transfermarkt-datasets

可直接复用：`appearances` 每行对应一名球员的一场出场，包含 `appearance_id/game_id/player_id/player_club_id/date/competition_id/minutes_played`。`player_club_id` 明确指比赛当时所属俱乐部；`player_current_club_id` 指当前所属俱乐部，SQL 直接从最新 players 表连接，因此后者不能作为历史成员身份。实际表名是 `appearances`，没有核实名为 playerappearances 的独立表。[出场 schema](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/transfermarkt_datasets/assets/cur_appearances.py)、[生成 SQL](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/dbt/models/curated/appearances.sql)。

`transfers` 已验证 `player_id/transfer_date/transfer_season/from_club_id/to_club_id/from_club_name/to_club_name/transfer_fee/market_value_in_eur`；可用 `player_id` 连接出场分钟，按历史 club ID 识别进出。schema 声明主键为 player_id + transfer_date；并无独立 transfer ID 或日内排序字段。费用未知为 null、自由转会为 0；不能由费用推断全部租借状态。[转会 schema](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/transfermarkt_datasets/assets/cur_transfers.py)、[转会生成 SQL](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/dbt/models/curated/transfers.sql)。

覆盖与时效：配置包括 2012–2025 赛季、主要欧洲联赛等，但这是采集配置，不能等同逐场完整率。维护者确认出场截止 2026-06-28，2026/27 阵容未覆盖；转会仅包括截至 2026-07-11 已录入的已公告事件，可能有未来转会日期，2026 夏窗不完整。因此无法提供本轮完整离队清单。[采集配置](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/config.yml)、[维护者时效公告](https://github.com/dcaribou/transfermarkt-datasets/discussions/383)。

短板：transfer_date 是源数据转会日期，正式注册生效时间 unknown；逐条 announced_at、first_seen_at、历史修订时间均 unknown。公告整体截止日不能替代每条事件的可知时间。只能做事件日期意义的成员推断，不能声称历史时点已获知离队。

价格/注册/许可：项目免费，公开 R2 读取无需凭据；仓库许可证为 CC0-1.0。上游 Transfermarkt 及第三方权利是否全部被该许可覆盖，本轮未证实，记 unknown，不作额外法律结论。[公开访问说明](https://github.com/dcaribou/transfermarkt-datasets/blob/master/docs/developer-guide.md)、[仓库许可证](https://raw.githubusercontent.com/dcaribou/transfermarkt-datasets/master/LICENSE)。

判定：历史候选数据源；当前阵容/离队完整性不满足本轮用途。历史验证仍需少量 2022–2026 样本与覆盖测量。

## 2. API-Football / API-SPORTS 官方服务

可直接复用：官方文档确认 `/players` 按 team、league、season 组织统计，同季转会可有两个队的统计块；球员 ID 跨球队保留。已验证赛季统计字段路径 `statistics[].team.id`、`statistics[].league.season`、`statistics[].games.minutes`、`statistics[].games.appearences`（原始拼写）。`/fixtures/players` 提供每场球员分钟，但本轮未解析其精确 minutes 嵌套路径，记 unknown。[官方字段文档](https://www.api-football.com/documentation_v3)。

`/transfers?player=ID` 或 `?team=ID` 提供转会历史；官方指南确认转会日期、type 及 `teams.out/teams.in`，type 可含费用、Free、Loan、N/A。本轮完整 transfers JSON schema 未成功解析，精确 date/update 路径记 unknown，不能凭常见客户端写法补齐。[官方指南](https://www.api-football.com/news/post/how-to-get-started-with-api-football-the-complete-beginners-guide)。

注册信息边界：`/players/squads?team=ID` 是当前队伍名单；不接受历史 season/as_of 的已核实接口。正式历史注册生效日、逐条官宣/first_seen 时间、历史名单快照均 unknown。当前 squads 不可回填旧赛季。逐场分钟可以按此前已结束比赛累积；整季 minutes 无赛前截止保证，不能直接输入赛季中回测。[官方接口文档](https://www.api-football.com/documentation_v3)。

历史覆盖：官方提供 seasons 与 league-season coverage 查询，但本轮没有密钥调用；2022–2026 各联赛实际分钟/转会完整率 unknown。免费可用赛季受限，不能依据网上其他用户描述确定当前免费年份。[官方价格](https://www.api-football.com/pricing/)、[官方条款](https://www.api-football.com/terms)。

价格/注册/许可：需注册 API key。官方列示 Free $0、100 请求/日；Pro $19/月、7,500/日；Ultra $29/月、75,000/日；Mega $39/月、150,000/日。服务条款允许制作应用等项目，禁止未经许可直接转售原始数据，并提示部分第三方内容可能另需授权；不是已确认的开放数据许可。[价格](https://www.api-football.com/pricing/)、[条款](https://www.api-football.com/terms)。

判定：值得做一组小样本 API 验证；本轮仅文档可行，没有实际数据接入或付费注册。不能保证补齐历史注册/官宣时间。

## 无需本场首发的候选量与限制

设 t 为赛前截止，W 为此前固定窗口，m(p,c,t) 为 W 内球员 p 为队 c 实际出场分钟之和（每场日期 < t）。候选量为：

`sum_p m(p,c,t) * I(p 在 t 仍属于 c) / sum_p m(p,c,t)`

分母必须只用此前比赛分钟，球员按当时 club ID 归队。分子可由完整转会事件链推断：离开 c 且生效日期 < t 时扣除，返回后恢复；转会当天没有时分则状态 unknown。无需目标首发。

两源都没有本轮验证过的逐条历史可知时间和正式注册日，缺失转会也不意味着仍在队。因此目前只可将它标为“按记录转会日期的连续性代理”；已知离队分钟占比可以单独保存，1 减去它在漏记离队时只是留队占比的上界。用于严格赛前回测仍有事后补录泄漏风险。当前采集时间只能证明从现在起何时观测，无法补回历史 known_at。

下一步最小实测（本轮未执行）：选一个有明确日期边界的 2022–2026 历史俱乐部窗口，验证球员/俱乐部映射、分钟覆盖、少量转会链与同日歧义；若没有历史时间证据，仍保持代理标签。未新增 hash、contract、baseline 或 gate。

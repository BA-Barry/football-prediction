# 下一步具体方案：复用现有平局信号，保留原主客方向

本文件是可讨论的结构设计，不是已经上线的新模型。当前概率、首选与生成时间均未修改；本轮没有训练或选择新参数。

## 为什么要改变这一层

同日三条统计线在1732场已有历史上共同错746场，其中440场为平局、306场为主客方向反选。丰富模型的全部总球均值超过独立Poisson平局首选的结构边界；只微调主客进球分配，不能让它选择平局。这不代表440场平局都可预测，也不证明缺的只是算法。

三条路线已有共同基础，不应继续把其中一个整体判为无用。现成的直接三分类未改善总体指标，但其中的逐场平局信号仍可单独复用，而不一并采用其主客判断。

## 推荐的分工

1. 现有丰富模型继续估计两队攻防，并提供在比赛分出胜负条件下的主／客胜比例。
2. 只取已有121项分类树的逐场平局概率。它从相同赛前信息学习每场的区别，不是统一抬高平局概率。
3. 剩余的非平局概率按原主／客比例分配，再使用已有score_reconciliation统一比分、总球和让球输出。

设原概率为pH、pD、pA，分类树的平局概率为d(x)：

```
qD = d(x)
qH = (1 - d(x)) * pH / (1 - pD)
qA = (1 - d(x)) * pA / (1 - pD)
```

该设计保留qH/qA=pH/pA，不平均多条路线、不重学主客方向、不新增融合权重。它相当于对平局与非平局两个比分区域作逐场概率重分配；区域内部原有的相对比分概率保留。统一后的比分均值和总球必须从新网格重新计算，不能继续引用原独立Poisson均值。

这会改变核心输出关系，因此按用户此前“重大模型调整先讨论”的偏好，先呈现设计，再决定是否实跑。

## 已有资产怎样复用

- `early_outcome_learners.py`：复用已有分类树及其时间外概率中的平局分量，不重新试一批三分类算法。
- `score_reconciliation.py`：直接复用已有H/D/A区域缩放，保持比分、胜平负、总球和让球内部一致。
- 既有条件正平局研究：复用按条件事件调整比分的表示与经验。旧版本只含截距＋强弱差，并只倾斜正比分平局；本方案使用逐场d(x)并涵盖0:0，不能把旧两个系数搬来冒充新学习。

## 能解决什么，仍解决不了什么

该分工允许平局成为首选，但保留原主客方向错误，因此无法单靠这项改造修复共同错误中的306场反选。没有证明当前特征足以识别平局；也不保证改变概率后能改善单选或总球。

只读检查已有提前3日分类树：2024/25平局概率最高36.78%，超过1/3有48场；按分工公式，仅4场平局成为首选。2025/26最高37.56%，超过1/3有42场，分工后13场平局首选。这里仅核对结构能否产生平局选择，没有以赛果调参数，也不是改进幅度或准确率结论。

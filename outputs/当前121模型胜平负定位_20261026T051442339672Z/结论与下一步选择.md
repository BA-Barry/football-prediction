# 当前121项模型：本轮结论与下一步选择

本轮使用现有的历史赛前预测，主口径为提前3日、2024/25与2025/26各1,726场。提前1日仅作重叠比赛的敏感性核对。新增训练、校准、参数搜索均为0；没有查询当前赛果、修改正式模型或LLM预测。所有新增文件在G盘。

## 找到了哪些重复现象

| 固定诊断 | 2024/25 | 2025/26 |
|---|---:|---:|
| 均势组平局平均概率 | 25.12% | 25.65% |
| 均势组实际平局比例 | 27.09% | 28.76% |
| 均势组较弱方胜概率高估 | 2.46个百分点 | 3.26个百分点 |
| 明显强弱组较弱方胜概率高估 | 2.46个百分点 | 2.53个百分点 |
| 整体平局AUC | 0.5670 | 0.5768 |
| 整体主胜平均概率偏差 | +1.19个百分点 | −1.15个百分点 |
| 明显强弱组平局平均概率偏差 | −1.76个百分点 | +0.14个百分点 |

均势／明显强弱的划分沿用旧研究定义：goal基专家较高与较低预期进球的比率小于1.5／不小于1.5。热门、较弱方也由这个赛前专家定义，不按实际赛果决定。

较弱方获胜概率偏高、均势组平局概率不足值得继续研究；整体主胜偏差却换了符号，因此不支持统一增加主胜概率。明显强弱组的平局偏差也未跨季一致，不支持给所有比赛统一抬高平局。

AUC是排序辨别指标，不是命中率。平局AUC接近0.57表明本模型区分具体平局比赛的能力较弱；不能仅修正平均平局比例就声称识别能力改善。本轮没有估计70%命中率上限，也没有证明新的结构必然有效。

## 逐格比分给出的限制

全体0:0两季预测103.2／113.7场，实际99／111场，点估计略高，但两季条件区间均跨零，不能视作已经确认的高估；1:1预测184.2／192.6场，实际210／203场。其他平局（2:2及更高）预测111.5／106.1场，实际122／126场。

均势组1:1分别预测99.7／110.8场、实际120／120场；但其他平局的缺口并不两季相同。不能把所有偏差归为一个稳定的1:1常数。

标准Dixon–Coles在固定进球率下会对0:0与1:1增加相等绝对概率，同时从0:1与1:0等量扣除。当前缺口不是这种整齐形态，所以不直接据此运行全局DC修正。单纯零膨胀也没有针对本轮主要缺口。

0次平局首选、漏掉431／440场实际平局只是单选错误的描述，不能据此认定所有这些平局本应预测正确。事后删除实际平局后计算命中率，不是赛前可执行策略。

## 本轮查阅的成熟项目与边界

| 来源 | 可以借鉴什么 | 当前决定 |
|---|---|---|
| [footBayes](https://github.com/LeoEgidi/footBayes) | 联合进球、单独的平局混合成分及比分分布统一输出 | 作为结构候选来源，未安装或训练 |
| [footBayes的Stan接口说明](https://raw.githubusercontent.com/LeoEgidi/footBayes/master/man/stan_foot.Rd) | `diag_infl_biv_pois`可分别分配0:0、1:1、2:2、3:3的混合质量 | 其原模型会学习球队强度；不是直接给当前121模型插入一个开关，也不自动保持原预期进球 |
| [footBayes的MLE接口](https://raw.githubusercontent.com/LeoEgidi/footBayes/master/man/mle_foot.Rd) | 确认实际支持范围 | MLE列表没有对角膨胀模型；不能声称所有模型都能走同一轻量拟合接口 |
| [PyPoisson](https://github.com/tchang1997/pypoisson) | Python的对角膨胀双变量模型与EM实现 | 查阅了实现，未导入；不能把演示项目视为已验证本项目效果 |
| [penaltyblog模型说明](https://penaltyblog.readthedocs.io/en/latest/models/overview.html) | 本项目已有包和统一比分输出可继续复用 | 旧球队Poisson/DC/双变量研究不是当前121固定进球率的同一对象，也不因更换对象就机械重跑全部方法 |

footBayes为GPL-2，PyPoisson仓库标注MIT。当前仅查阅，没有复制这些新项目的源文件或安装R／Stan。正式采用时应保留实际复用代码的授权说明。公开项目提供成熟思路，不等于它在我们的早期可用资料上必然提高预测。

## 下一步建议与讨论范围

建议优先研究均势比赛的平局辨别与联合比分结构，保留当前统计模型和独立LLM线路。候选必须区分“平均频率修正”与“哪些具体比赛更容易平局”；共同权重的平局混合只对原平局概率作单调变换，无法单独提升其AUC，不能将其当作全部问题的解决方案。

这涉及核心比分层，已按用户希望重大改动先讨论的偏好发出方向选择：先研究平局与联合比分，或先补无需首发的球队变化信息。待方向明确后确定一套可执行的独立研究方案，不同时扫多种分布、窗口或联赛权重。

本轮到两提前量的固定类别诊断和提前3日的六个逐格汇总结束，不再加拟合、调参或新赛果复核。诊断文件保留；没有启用任何概率修正。完整数值见偏差与错误定位.md、低比分逐格定位.md和对应JSON。

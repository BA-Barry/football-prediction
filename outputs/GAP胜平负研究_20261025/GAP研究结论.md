# GAP胜平负研究：已接通、完成前推，暂不替换

本轮已将此前提出的GAP动态比赛统计路线接入真实历史数据，直接复用statsmodels有序回归，完成22次历史时点训练和3,452场提前三个日历日的胜平负预测。它明显优于此前的普通多项分类器，但没有超过现有较强的丰富信息进球回归线。因此保留可复用代码、模型与结果，结束本轮研究，不通过增加参数组合继续救分，也不改变已经发出的比赛预测。

## 本次真正新增了什么

1. `model_v2/src/football_model/gap_model.py`：四项统计分别维护每队主场进攻、主场防守、客场进攻、客场防守状态。四项统计为真实进球、射正、非射正射门、角球。
2. `model_v2/src/football_model/gap_outcome.py`：用赛前预期统计的四个主客差直接学习胜平负概率；每个历史时点保存可重新加载的模型。
3. `work/run_gap_20261025.py`与`work/evaluate_gap_20261025.py`：串起历史状态生成、训练、保存、预测及同场评分。

状态方程借鉴[Wheatcroft 2021论文](https://journals.sagepub.com/doi/10.3233/JSA-200462)，概率层直接使用[statsmodels OrderedModel](https://www.statsmodels.org/stable/generated/statsmodels.miscmodels.ordinal_model.OrderedModel.html)的原生似然拟合和预测。不是照搬Github同名项目，也不是复现论文的利润。之前核读的两个同名代码存在具体实现或许可问题，因此没有复制；调研细节见`outputs/多项进攻统计接入_20261025/GAP方案与取舍.md`。

statsmodels 0.15.0及新依赖已装入G盘虚拟环境，许可证副本位于本目录`upstream/`，安装路径详见`复用组件.json`。既有C盘数值运行库只读使用，新代码、模型、数据、临时目录及缓存位于G盘。

## 概率如何形成、如何变化

对每项统计，先用双方当时的攻防状态预测主客计数：

```
预期主队计数 = (主队主场进攻 + 客队客场防守) / 2
预期客队计数 = (客队客场进攻 + 主队主场防守) / 2
```

比赛结束后，以实际计数与预测计数的误差更新相关状态；同一场的全部更新都从更新前状态计算，状态下限为零。每项统计的学习率lambda和两个主客迁移比例，仅由2022/23赛季1,825场的计数绝对误差学习，此后不按检验季胜平负成绩重选。

状态仍随此前已完成的比赛推进。四个预期主客差经训练集标准化后，进入有序logit：

```
z = 四个标准化主客差 × 四个学习系数
P(客胜) = sigmoid(c1 - z)
P(平局) = sigmoid(c2 - z) - sigmoid(c1 - z)
P(主胜) = 1 - sigmoid(c2 - z)，其中c1<c2
```

每个训练时点只用更早比赛学习四个系数和两个阈值；22个训练时点沿用旧路线的日期，约每28天更新一次。状态变化与概率映射更新是两个不同步骤。这是可解释的训练模型，公式负责计算，参数从数据学习，不是手写固定主胜比例。

本轮采用最大似然而非原论文所述最小二乘映射；计数目标包含全部2022/23比赛，没有原文的六个主场比赛预热排除；映射历史等权，也不同于某些旧路线的180天衰减。因此同场比较衡量整条本地路线，不能把成绩差异单独归因于角球或某一个算法。

有序logit用同一组系数区分客胜、平局、主胜，对逐场平局形状有约束。新球队借用此前同联赛离队球队平均状态，是明确的点初始化假设，不能视为已经学习出升班马真实实力或其不确定性。

## 数据与时间口径

- 数据为此前接通的20份Football-Data文件，2022/23—2025/26五大联赛；沿用7,062场有效历史记录及原有20场排除，本轮没有新增排除。
- 2022/23学习12个统计更新参数；2023/24生成较早的预测状态，用作胜平负映射初始训练历史。
- 2024/25和2025/26分别保留旧路线同场的1,726场，共3,452场。完整两季状态共3,490场，另外38场未扩入本轮同场比较，不用新路线的覆盖变化抬高成绩。
- 每场状态只吸收日期严格早于F的比赛，F为目标日期减3天；映射训练标签日期严格早于P，并要求P≤F。日历日期口径不等于已重建精确T−72小时，原始统计首次公开和修订时间未知。
- 赛季参赛队身份视为当时可从赛程获知；没有使用未来战绩初始化。没有读取本轮2026/27赛果、目标首发或新赔率，也没有按刚结算五场调整参数。
- 两个后季已在此前研发中查看过；本轮是历史接入比较，不是全新盲测。结果不能直接解释为当前比赛命中率。

## 同场结果

每季所有下表路线均为相同1,726场。Log loss为自然对数损失，越低越好；命中率仅指最高概率的一个胜平负选项是否命中。

| 路线 | 2024/25 Log loss | 2024/25命中率 | 2025/26 Log loss | 2025/26命中率 |
|---|---:|---:|---:|---:|
| 本轮GAP | 0.982824 | 52.78% | 0.996075 | 51.51% |
| 丰富信息进球回归 regression_allcomp | 0.980302 | 53.48% | 0.992373 | 51.68% |
| 原进球线 goal | 0.989450 | 52.43% | 0.997272 | 51.56% |
| 独立xG线 xg_raw | 0.983069 | 53.13% | 0.995323 | 52.03% |
| 此前多项分类 logistic_allcomp | 1.038231 | 49.71% | 1.049368 | 49.83% |
| 既有干净融合 clean_blend | 未列该季对照 | — | 0.993864 | 51.85% |

GAP的Brier分别为0.585906、0.593822；丰富信息进球回归分别为0.583219、0.590923，两个后季同样未被GAP超过。

2024/25，GAP相对丰富信息进球回归的Log loss差为+0.002522，四周时间块条件95%区间约[−0.003948,+0.008649]。2025/26，相对既有干净融合差为+0.002212，区间约[−0.006844,+0.008542]。这些区间均跨零：不能断言GAP必然较差，也没有足够依据宣称它提升了预测。区间只针对保存的预测，不包含参数估计及多轮研究选择的不确定性。

GAP平均平局概率为26.05%、25.94%，实际平局比例为24.97%、25.49%。这个总体均值较接近，不足以证明逐场平局判断更好；本轮整体概率评分仍未胜过较强旧线。完整分联赛结果保存在`GAP同场评价.json`，不按其中某个联赛挑选上线。

## 本轮执行与停止决定

实际完成4次单起点统计参数拟合、658次目标函数计算（包含4次初始值评估）、22次有序回归拟合，未跑参数网格或优化器重启。完整历史训练执行约13.48秒，不代表数据调研、实现和测试所耗时间。22个模型均已保存并重新加载后用于生成预测。

11项针对性测试通过。另一次只读检查确认5,237条状态的历史前缀数量与最后日期正确，22个训练集合与其日期截点一致，3,452场的类别方向与比分一致；没有因此重跑训练。检查用于发现具体接入错误，不作为扩大实验的理由。

决定：**研究产物保留，正式预测不替换，GAP本轮到此停止。** 不自动增加窗口、变量子集、分联赛挑参、BA模型或神经网络，不按五场近期结算结果救分。

后续优化应先寻找现有信息之外、能提前获得的新证据，而不是再次变换同一批射门或xG的权重。优先调查赛季中教练更换及战术阶段变化的公开时间资料，评估它是否能解释现有模型对球队实力变化的滞后；它尚未进入本轮模型，不能声称已经增准。此前调研已指出[Heuer等2011](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0017664)没有支持普遍的换帅收益，因此不设置统一换帅加分。如需让这种信息改变核心状态更新方式，会先向用户说明外部依据、与已有跨季/动态状态研究的差别，再决定是否实施。

可复用产物包括本目录`统计更新参数.json`、`赛前统计状态.json`、`各次训练记录.json`、`models/ordered_logit_*.joblib`、`逐场胜平负概率.json`和两个GAP模块。该路线只输出胜平负；不能从三项概率推造总球、半全场或让球分布。

# 条件正比分平局：联合比分研究结果

较早2024/25的1,726场只用于学习两个系数；2025年8月1日固定，后季2025/26的1,726场完整检验。保留当前121项模型与原参数日期，不重训球队、随机树或LLM。两季此前均已查看，仍属回溯研究。

## 方法与复用

在每场原联合比分上，对1:1、2:2等正比分平局乘以同场系数，再对整个比分分布统一归一化。该系数由截距和赛前强弱差共同决定，允许增加也允许减少；0:0不单独乘该系数。

`d = abs(log(goal专家主队预期进球 / 客队预期进球))`

`eta = beta0 + beta1*d; Q(h,a) = P0(h,a)*exp(eta*I[h=a>=1])/Z`

本次学得beta0=0.189300，beta1=-0.106562。一次零起点BFGS，以完整比分概率损失学习；没有网格、重启、联赛专用参数或额外提前量。

借鉴[footBayes的对角比分机制](https://raw.githubusercontent.com/LeoEgidi/footBayes/master/man/stan_foot.Rd)，本轮是本项目的两参数条件化改编，并非将其原R/Stan模型原样导入。直接复用了本地既有比分网格、概率汇总和SciPy优化接口，没有安装新依赖。

## 能改变什么，不能改变什么

本轮最高选项改变0场，主胜与客胜之间的方向改变0场。该结构保持主胜／客胜概率比，因此不能纠正胜负方向选反；1:1与2:2等正比分平局内部相对比例也保持不变。它主要改变平局与非平局之间的表达，没有新增球员、伤停或战术信息。

最终主客预期进球的平均绝对变化分别为0.006367、0.006793。全部总球及让球概率由同一个新网格重算，不能把新均值再当作Poisson参数重新评分。完整比分NLL使用原解析Poisson NLL加logZ减实际正平局倾斜量，覆盖超出报告网格的高比分；S来自已保存概率，报告网格与此完整支持表达之间仅有原有可忽略尾截断差异。

## 本轮决定与停止点

完整胜平负平均概率损失下降，但当前仅有已查看后季的一次回溯对照；仍保留为独立候选，不替换正式预测。平局排序AUC点值提高，但未为其估计完整训练不确定性，也不能据此宣称命中率上升。本轮重点均势组的平局排序未改善，说明主要收益仍是概率量级表达，尚未解决该组逐场辨别。总进球概率评分变差；正比分平局共用系数也使1:1与较高平局无法分别校正。

到这一组两参数学习和既定后季完整比较为止；不根据结果增加形状参数、改变窗口、拆联赛训练或再扫其他分布。当前比赛正式模型、LLM结果和已发布预测均未替换；没有复核当前赛果。

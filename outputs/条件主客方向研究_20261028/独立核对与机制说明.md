# 条件主客方向研究：独立核对与机制说明

审查通过。独立重建 22 个时间窗的训练样本；3452 场目标全部保留，两季各 1726 场。训练比赛均严格早于各窗参数日，参数日不晚于预测资料日，资料日早于比赛日。q 的训练 ID、中位数和缺失指示仅来自更早非平比赛；已有 d 的全部训练 ID 也符合时间边界。保存模型只作预测重放，3452 个 q 均一致，没有重新拟合。22 窗树配置与已有三分类树配置逐项相同。

q、d 合成、比分网格、胜平负、总球、均值、让两球、实际比分损失和全部汇总相符，最大数值误差 7.77×10⁻¹⁶。具体结果保存在 `独立核对.json`。

新 q 大体保留原来的排序，相关系数分别为 0.987 和 0.980，但概率更分散，平均略向主胜移动。主客顺序翻转分别为 71 和 104 场；翻转场原 q 距 0.5 的中位数约为 1.6 个百分点，说明多数翻转发生在原先接近均势的位置，但也存在较大幅度翻转。这里是结果描述，不能据此断言单个输入造成了变化。

早季单选多对 8 场，对数损失却变差：纠正比赛带来的总损失下降约 2.369，改坏带来的上升约 2.278，而单选方向未变的 1655 场合计损失又上升约 2.578。由此可见，不能只数改向对了几场，还要看每场概率分配是否合适。晚季多改坏 9 场，对数损失仍有极微小改善，原因同样是单选与完整概率评分评价不同对象。

d 固定，因此相对同 d 线路，平局／非平局损失没有实质变化，HDA 对数损失差完全来自条件主客方向。然而三选一中的“平局是否最大”仍会变化：d 必须同时超过 (1−d)q 和 (1−d)(1−q)。因此 q 改变能改变平局是否被选中；它没有学到新的平局信号。两季实际平局分别为 431 和 440 场，新线路仅选平 5 和 11 场。

比分网格沿用 state_rich 的条件比分形状，再缩放 H/D/A 三个区域。与已有同 d 线路比较时，比分和总球差异还包含两者来源比分形状的差别，不能全部归因于新 q；本轮没有学习新的条件比分机制。

历史前推已排除本项的目标混入训练，历史赛季多轮用于研发的事实仍然存在。本轮没有形成跨季稳定修复主客反选的证据，按既定停止位置结束，保留组件与学习结果，不据此替换当前预测或追加参数搜索。

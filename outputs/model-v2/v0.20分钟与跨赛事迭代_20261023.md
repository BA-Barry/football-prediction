## 1. 球员分钟：从事后路径走向赛前输入的一项实测

新增 `prematch_minutes.py` 与 `prematch_minutes_research.py`。每场仅使用同队、同来源、严格更早日期的完整固定45+45分钟历史曝光，不输入目标首发、替补、实际换人或实际出场球员名单。最近一场和最近5场平均两方案均保留；5场按球队比赛数为分母，不按某球员出场次数计算。

无历史返回未知，不当作球队所有人0分钟。当前名单、转会、伤停、停赛、位置与门将轮换未知。历史红牌、临时离场造成的缺额不强补到990，不自动转成完整合法的 `Lineup`，不将未预测新身份当作已训练的零球员效果。

真实重用2015/16 StatsBomb原秒级固定窗口378场、2017/18 Wyscout共同374场三套近似时钟；2月1日后分别148／128场共同目标，去重276场，不假定同队连续比赛统计独立。共2,128条球队分钟候选，0次新增优化器拟合。

评价使用两方案候选和实际正曝光球员的同一并集；先逐队计分再两队平均到比赛，实际新ID只进误差与遗漏统计，不倒灌候选。全部候选、历史比赛ID、遗漏分钟、分配给实际未上场者的分钟、SD／中位数／范围保留。源历史第一次公开时间未知，“日期次日可用”只是研究假设。两季已查看，且年份／提供商／时钟同时变化；只评价固定45+45窗口，不冒称补时完整分钟、新盲测或赛前可交易验证。

## 2. 跨赛事：真实接入了哪些连接，尚缺什么

新增 `cross_competition_probe.py`，读取openfootball公开社区数据库的2023/24、2024/25欧冠／欧联／欧协6份文本，以及README和LICENSE，合计84,365字节。仓库声明CC0，但不是UEFA官方发布接口；源记录事实尚未独立全部验证。

938行均解析，双方连入现有同季五大联赛CSV的186场，其中不同联赛177场；383场只连接一队，369场两队都不在五联赛范围。只使用国家限定精确名称或小规模显式人工别名，不模糊匹配、不去重音、不自动去FC。全季球队名单只作事后身份覆盖测量，不作为当年赛前预测特征。

910行未标注加时比分，28行有加时／点球标注。全部数字、原文、阶段、日期推导与来源接收时点保留；本轮不猜加时括号含义，90分钟比分与中立场均未核实，不进强度训练。日期未知／星期冲突／拒绝行／重复均为0；源头部计数一致不是独立事实证明。欧战强队选择性、同队重复与两回合相关仍存在，不能由连接行数推出联赛强弱。

## 3. 较新球员数据：目录完整不等于已可训练

本轮核对了真实来源与小样本：IMPECT 2023/24男足德甲目录306场、18队各34场、主客组合完整，但尚未下载事件／阵容整包、训练或证明在场时长可用。StatsBomb同季男足德甲只有勒沃库森34场，不是完整联赛；MLS2023仅6场。较新完整女足赛季只能另列方法验证候选，不自动混入男足或替换当前目标。

这些不是2026当前阵容来源。下一步应先少量较新男足事件实测，核对半场编码、真实换人与战术位置变化、红牌、终场及出场时长，再决定是否扩大本地分析。许可、字段文档、实际样本与时间边界详见[较新球员数据可行性报告](G:/Codex/football-prediction-2026-10-22/outputs/model-v2/较新球员数据可行性_20261023.md)。本轮没有对外转交数据、注册提交身份或新增付费服务。

## 4. 下一步顺序和讨论边界

1. 少量较新男足事件时钟／换人／红牌／终场实测；源已发生不等于历史当时已经发布，两者分开记录。
2. 补当前可用名单、预计首发与替补情景，再比较分钟候选；不能用实际目标名单筛选历史。未知球员、缺阵、转会保持未知，不能无依据填0或等权分分钟。
3. 核实欧战90分钟比分与中立场，增加可靠跨赛事负荷，再研究层级桥梁；不先套Glicko默认参数或战意胜率加分。
4. 球队边际强度转为条件参考阵容强度、联合分层、新球员先验或神经网络属于显著结构选择，带着数据、同场设计和风险先与用户讨论，不悄悄替换。

本轮实验设计技能使候选限定为同场／同来源／严格历史对照；统计分析技能使全部候选、遗漏和比赛级误差保留，不作球员行级IID检验。技能影响的是研究和报告方式，不是新增发布门禁。

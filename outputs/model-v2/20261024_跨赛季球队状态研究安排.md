# 跨赛季球队状态：拟合前研究安排

用户已明确同意“先做跨赛季球队状态对照”。本安排在任何本轮真实赛季拟合之前保存；历史资料此前已被研发查看，不是预注册盲测。使用实验设计及统计分析技能，重点是隔离球队强度层、保留同场比较与完整负结果，而非增加前置门禁。

## 预测问题与保持不变的部分

只研究：在同一套较早赛果上，让球队攻防强度跨季延续、在换季允许发生变化，是否优于原来的单一球队系数？

保留原独立Poisson进球分布、原主场／赛事项和截距、alpha=.01、180天半衰期、按28天更新、同一拟合器与数值容差。训练仍只使用严格早于cutoff的赛果，每条比赛在一次联合目标中只出现一次，不叠加原预测均值或短期残差；重复在下一窗重估不被计为新的比赛证据。现有球员、LLM、市场和当前9场前瞻均不修改。

与原28日快照内动态残差的区别是：这里的球队×赛季项在每次联合拟合中连接以前赛季，不在新快照把历史状态残差归零；这是季节分段强度模型，不冒称逐日连续状态空间滤波。与共享英超／英冠身份的区别是：本轮不新增英冠训练、级别差或升班马折扣。

## 固定模型与有限选择

每队的进攻／防守强度＝首次历史出现赛季的基础效应＋q乘以后各年度创新之和；防守沿原模型的负号进入对手进球率。基础、创新和原主场／赛事系数沿用同一ridge。每队起始年仅由当前训练history决定，不用未来赛程成员；首次出现赛季没有此前创新。若球队在本地英超中缺席了一个赛季，该日历年度仍在累计间隔内，不把两年间隔压成一年。

只比较预先确定的三个相对创新尺度：q∈{0,.5,1}。q=0直接恢复原特征和原模型，不是另换正则的参照。q是既定惩罚目标中创新相对基础效应的尺度，不是识别出的真实季间波动方差；它也改变有效正则与可变性，不能把效果因果归于真实季间信号。归一化加权损失的ridge语境与旧模型相同，不声称固定绝对贝叶斯先验方差。

尚无本季结果时，已知球队的新季创新采用MAP条件均值0，承接最近状态；这不表示已知球队没有变化。本轮只比较点估计，不积分季间／参数后验不确定性，也不据此降低实际预测风险。完全未知球队明确缺失，不填0、不用全季名单反推，也不回退其他线路。缺席年度的共线创新由既定惩罚分摊，不能把分量说成数据分别识别的各年变化。均值／攻防平移采用proper ridge下的惩罚约定，不解释为因果球队价值。

## 评价、覆盖与解释

主目标是解析完整比分NLL，辅助1X2 Log loss／三类求和Brier／精确并列期望Top1、总进球0/1/2/3/4+损失／Brier、客让两球三项损失／Brier。让两球净胜至少3球才让胜，沿原分布评分，不产生本轮投注推荐。

每季完整目标380场，分别列所有线路覆盖、缺失ID／原因和共同样本；只有共同样本的配对差才能比较。预计早期373场共同支持，晚期各378场；这是拟合前从既定28日窗及历史身份推算，不是按误差删场。

预定按窗口／月、开季8–9月与其余、双方都参加上季英超与至少一方未参加分组。后一个分组只作评价标签，不作为模型特征，不能以其改善声称识别了跨级实力。多指标、多窗、同队重复比赛不是独立重复实验；完整报告方向与幅度，不给未经依据的显著性／抽样区间／收益或盲测结论。

另保留互斥的本地首次出现／缺席后回归／连续英超身份：若涉及一队在此前所有本地EPL历史从未出现，先归首次；否则若至少一队不在上一季，归回归；其余归连续，只作描述而不再按组选择q。早期2023/24没有回归球队，因此不能称季间尺度已在早期学到缺席期演化。较晚Leicester／Southampton／Burnley的1年、Leeds的2年缺席规则是外推；原缺席年与回归当季创新可能同列，须保留惩罚分摊的解释限制。

无论结果正负，后两个赛季不再改q、半衰期、惩罚或赛季边界；不自动替换当前模型。若效果不稳定，优先解释缺失和季间大变化的限制，不在同一个目标季追加参数。未来若要加入伤停、球员或赛事投入情景、后验积分或深度学习，再讨论相应结构与数据。

# 用户已同意：分层收缩与未知球员不确定性研究

先完成v36负增量诊断，用户选择“先做分层与未知球员研究对照（建议）”。本文件在真实新模型拟合前记录具体安排；旧模型、原123同场及9场前瞻均保留，不自动上线。

数据为现存2023/24德甲306场及独立Football-Data全场比分；开场位置逐场映射GK/DEF/MID/FWD，不按全季众数固定个人角色。138/421人曾跨角色，不能用未来角色倒填历史。新条件比v36多“开场角色已知”；源可能事后编码，缺原始公布时间，因此不是历史真实T−60信息回放。当前公开目录的已存观察仅743这一个赛季，不假设有更多同源免费赛季。

结构是固定方差的交叉加性角色＋个人残差，不是学习超方差。主、客完整进球对数率包含球队攻防、主场、双方中心化角色人数和个人首发偏差；每队角色均值、首发频率、ID和先验更新仅用当周一之前的比赛。未知个人没有新拟合列，其攻、防残差各保留N(0,s²/2)先验，给两侧预测协方差明确增加；不能把均值0说成实力确定为0，也不能将替补名册经历当已学到进球能力。

固定主尺度s=.10，来源只是旧求和ridge100的外部log-scale锚点，不是新目标最优。角色和个人每个攻防分量方差各s²/2、精度2/s²；主场／球队精度1、截距flat。固定s=.05/.20同时作先验敏感性，全部报告，不按本季成绩选赢家或改后续主尺度。未中心化单人角色＋残差方差才是s²；同角色替换时角色共享项会抵消，未知个人新增方差仅s²/2。恒1门将角色计数没有组效应数据证据。

MAP求和全场Poisson目标；完整观测Hessian给已知参数Laplace近似，未知个人先验单独积分。每场输出两维log-rate均值及完整协方差，并用Gauss-Hermite积分联合Poisson比分／胜平负／总球／客让两球概率；不是Poisson(Eλ)，不靠截断低比分网格冒充全尾。主积分15阶、固定25阶对照仅测数值误差，不据赛果选择阶数。Laplace误差和不确定性覆盖尚未由MCMC／真实前瞻校准，不声称完整贝叶斯或已校准置信度。

沿用2024-01-01至2024-05-18、18个有比赛周的周一严格更早日期前推、同周不更新。每周拟合球队Laplace与三尺度角色／首发Laplace，共72次；每份参数与精度Cholesky存盘载入再预测。主比较预先声明为s=.10对匹配球队Laplace、全部163同场完整比分NLL；1X2／总球／客让两球及top1全部保留辅助。旧球队MAP只作次要对照及数值重建，不把加入参数不确定性的收益全归因于球员。

在新拟合前固定旧v36已知123场／未知40场，分别报告且不删比赛；两子集不是独立实验，不能直接将不同队列均值归因。记录先验敏感性和数值敏感性，不正式检验p值、不把重复球队／重叠历史当IID、无抽样区间／稳定提升／因果结论。本季已被研发查看，不称盲测。全部代码、数据、模型、缓存、临时与产物在G盘；遵守IMPECT自定义个人非商用条款，保留署名logo，不再分发原始或派生观测。

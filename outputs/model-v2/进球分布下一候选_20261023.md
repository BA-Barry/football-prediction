# 进球分布下一候选：均值参数化 COM–Poisson

本轮仅归档候选，不新增 CMP 代码、不拟合、不训练、不改变正式预测。当前优先执行球队模型衰减速度 × 正则强度的真实重训，以隔离参数学习和比分分布的作用。

## 为什么保留，但不立即采用

现有两季条件 Pearson 平方减一点估计偏负，但它同时受条件均值错误、球队参数误差和样本构成影响，不能据此自动断言真实进球必然欠离散。0:0 偏高、1:1 偏低也不等于应把所有低比分统一放大；标准 Dixon–Coles 单一相关参数对这两个格子同向调整，不能单独同时完成这两种修正。负二项通常用于过度离散，也不能仅凭惯例替换 Poisson。

均值参数化 CMP 值得作为后续小规模候选：它保留非负整数的完整支持，并可围绕同一条件均值改变离散程度。可先仅学习一个跨主客共享的 ν，不同时引入联赛专属参数、相关项或新的均值修正。

## 必须保持的数学含义

将原模型逐场 λ 当作目标均值 μ，而不是 CMP 的自然速率 θ。定义

`log p(k | μ, ν) = kη − ν log Γ(k+1) − log Z(η, ν)`，`η = log θ`，`ν > 0`。

每个 `(μ, ν)` 必须求解 `Eη,ν[Y] = μ`，再计算完整归一化常数。`d E[Y] / dη = Var(Y) > 0`，可据此括区间求根。不能直接令 `θ = μ` 或只套大均值近似；足球进球均值较小，这会造成实质均值漂移。`ν=1` 应与原 Poisson 解析恒等。

## 尾部与数值实现要求

在 log 域计算权重 `w_k = exp(kη − ν log Γ(k+1))`。到达递减区后，令 `q = exp(η)/(K+1)^ν < 1`。由于后续相邻权重比递减，遗漏未归一化质量有上界 `w_K q/(1−q)`；一阶遗漏矩有上界 `w_K[Kq/(1−q)+q/(1−q)^2]`。应同时控制概率尾部及均值误差，不能固定截到 10／15 球再把有限网格归一化当作解决了问题。

完整比分 NLL 直接由 log pmf 计算，真实比分即使超过绘制网格也不删除、不改成尾箱。联合网格来自两边际乘积；保留原始保留质量、遗漏质量上界和截断均值误差。独立 CMP 不解决主客依赖，也不能预先保证平局、1:1 或大比分改善。

## 后续最小研究设计

使用已验证的较早时间外预测均值及真实比分，等比赛权重拟合一个 ν，截止日之后固定应用；所有基础预测仍须来自各比赛之前的训练。优化资源上限／数值失败或边界解应如实记录，不悄悄回退、裁概率或按较晚结果选 ν。两季已被查看过，仍只能称探索性时间外推，不能称新增盲测。

同时报告精确比分 NLL、1X2、总进球、让球三项风险、均值误差、零进球与 1:1／尾部；在同一比赛队列上与原分布成对比较。普通测试至少覆盖 Poisson 恒等、归一化、均值保持、尾界、支持外比分的 log pmf、主客互换、非法／极端输入及拟合日期边界。无需新增依赖或独立模型框架。

## 已核实参考与复用边界

- [Huang：Mean-parametrized Conway–Maxwell–Poisson regression models](https://arxiv.org/html/1606.03214)，第 2 节给出均值求根参数化；只参考方法，不复制其软件。上面的几何尾界由相邻权重比直接推导。
- [opisthokonta/goalmodel](https://github.com/opisthokonta/goalmodel) 明确区分 CMP 自然速率和均值，提供两步固定球队参数估计的思路。仓库为 GPL-3，当前不复制其源码，也不把其快速近似直接视作精确求根。
- 本地已安装 `penaltyblog 1.13.1` 有 Poisson、Dixon–Coles、负二项及 Weibull–copula 等实现，未见可直接调用的 mean-parameterized CMP 类。现有比分汇总工具可以复用，但不能用 Poisson 的截断规则冒充 CMP 尾界。

检查的较早 2024/25 存档共有 1,736 场、3,472 个主客均值，范围约 `0.48564–4.53747`。这里只测量了输入范围，未产生 CMP 预测或性能结论。

# 本轮决定：不将单温度校准用于当前英超预测

本轮已实际完成两次单参数学习，复用已有校准代码和已有历史时间外概率；没有重训球队或随机树模型，没有做参数网格，没有改原预测或复核当前赛果。全部新文件在G盘。

当前121项丰富模型以前没有应用过参数校准，故本次不是重跑旧Poisson模型的校准试验。2024/25学习一个五联赛共享温度，2025年8月1日固定后用于2025/26；提前3日为主要比较，提前1日用同定义核对。

| 后季比较 | 提前3日 | 提前1日 |
|---|---:|---:|
| 五联赛整体LogLoss变化 | −0.000848 | −0.000836 |
| 英超LogLoss变化 | +0.000775 | +0.000778 |
| 英超Brier变化 | +0.000626 | +0.000609 |
| 冲突组近期支持单胜的高估 | 2.15→1.68个百分点 | 3.22→2.72个百分点 |
| 最高概率选项变化场数 | 0 | 0 |

差值为校准减原样，负为更好。五联赛整体改善很小、4周条件区间略跨零；当前关注的英超在两提前量反而小幅变差。整体改善不能覆盖英超反向，也不能用冲突组一项偏差缩小代替完整三项概率表现。

**执行决定：保留研究文件，不将该校准用于当前英超10场，不替换已发布概率。到这两次拟合为止，停止追加温度网格、类别偏置、联赛专用参数或按后季挑选方案。**

温度保持正值时不改变胜平负排序，所以本来就不能提高最高单项命中率。它也没有形成新的比分分布，不能拿校准1X2与旧总进球、让球概率混算。外部方法来源与完整结果见丰富模型校准结果.md。

## 下一项值得讨论的核心改进：表达经过历史对手校正的近期表现

当前近期5／15场的xG、进球、压迫等主要是描述均值。目标场的基专家考虑主客与对手，但此前各场的描述统计并未充分按历史对手难度校正。弱队连续遇到强队，或强队连续遇到弱队，都可能产生误导。

一个可审阅的最小方案是新增独立研究线，保留当前121项及固定算法，只补两个对称输入：主客两侧各自最近5场的“实际xG净值减当时预期xG净值”的均值。

对某队历史比赛，先统一主客方向：

`历史表现偏差 = 该队实际xG净值 − 该场当时较早xG专家预期净值`

每侧一个近期均值，共两列；不增加神经网络、手写战意系数或球员扣分，也不同时改变比分分布。训练目标仍是全场真实进球。

这比直接按连胜连败加减概率更贴近问题，但仍依赖既有xG专家，不等同真实因果实力。应先与用户讨论结构再训练，当前没有实施或声称有效。

## 已查明的实现边界

- 缓存里有每场较早的xG预期，但没有该场实际xG；实际值须从已精确连接的数据记录读取，不能用后续滚动均值反推。
- 并非所有历史比赛都有合法较早预测；缺少时要保留未知和可用数量，不能补0，也不能跳过缺项悄悄取更早5场。
- 每个历史输入须遵守其原发布日与训练日，禁止用今天的xG模型倒推过去。
- 当前2026/27最近比赛缺少对应合法较早xG均值缓存。若历史研究有效后采用，需要按那些比赛各自更早截点重放基专家，或保留未知；不能用10月26日已看过同场结果的专家回算。该准备成本尚未执行。
- 当前预测提前5—7日，既有历史主要提前1／3日；该适用范围仍须如实报告。
- 本轮仅完成可行性核对和方案说明，没有新增该结构的特征或训练。

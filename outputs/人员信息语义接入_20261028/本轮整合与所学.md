# 人员新闻与既有模型的整合：本轮完成与所学

本轮实际完成于北京时间2026年10月29日；目录名20261028沿用原任务标识，文件内另存真实UTC时间。新增文件全部在G盘。本轮完成了新闻语义、同截止历史对齐、此前参与证据和LLM资料理解的接通；没有新增拟合、调参、赛果查询或修改旧预测，因此没有新的准确率结论。原213项研究模型保持。

这次补充解决一个具体问题：同样的“不可用”标记，可能指伤病、比赛适应度、停赛、租借或选择限制；同样的伤病文字，也可能早已连续出现在形成近期战绩的几场比赛之前。联合分析需要先弄清这些差别，才有理由判断是否存在模型尚未反映的信息。

## 从这批记录中学到了什么

同队同球员可配对的525,981组来源对照中：

| 状态／原文比较 | 引用组数 |
|---|---:|
| 状态和文字都相同 | 439,309 |
| 状态与文字都变化 | 76,716 |
| 状态相同、文字变化 | 9,930 |
| 文字相同、状态变化 | 26 |

9,930组“同状态、文字变化”中，8,769组（88.31%）仍属于相同文字类别；5,291组涉及预计归期措辞变化，2,479组涉及来源百分比变化，3,922组原因段文字变化。这些项可以重叠。因此，不能把文字更新统一解释成新伤情，也不能因同为d就认为信息完全没变。`news_added`也不是每次全文变化的可靠更新时间，使用的是各版快照的实际观察证据。

医疗文本引用共12,606条，其中9,332条具备已匹配身份及完整近期分钟证据：4,546条近期有分钟，4,786条近期0分钟；后者中3,776条在更早同队资料里曾有正分钟。其余3,274条近期窗口未知。这些是跨场重复引用，不能称为12,606个独立球员或新增训练样本，也不能把0分钟解释成零能力。

三例实际阅读进一步说明了联合分析应如何使用这些信息：

- **Kelly／Newcastle–Brentford**：完整近5场合计1分钟，当前为“Loaned to Juventus”，4个较早快照已同状态同文字。这补充的是人员隶属原因；不能只因当前仍挂不可用就额外按主力缺席扣分，也不能由1分钟判断能力低。
- **González／Wolves–Brentford**：完整近5场0分钟，更早同队曾有正分钟，5个参考快照均为同一膝伤／归期未知文字。近期表现可能已部分反映当时的人员组合；没有反事实效应估计，不能断言已经全部反映，更不能把0分钟归因于伤病。
- **Lamptey／Tottenham–Brighton**：近5场100分钟；一个参考快照为d／踝伤／50%，当前为d／膝伤／75%。单看标记会遗漏原文差异；75%与50%都是源值，不能直接当校准出场概率，更不能相减后换算球队胜率。

三例LLM都将“支持数值概率修正”保留为unknown，效应与概率增减为null，未执行扣分。null表示未估计，不能解释为真实效应为0。资料可供理解，不等于已学会替代者质量、针对战术或个人边际贡献。

## 模型、LLM和助手现在怎样协作

| 角色 | 本轮接通的实际作用 | 当前边界 |
|---|---|---|
| 统计模型 | 原真实进球、近期表现、赛程、状态及教练观测共同输入保留 | 本轮没有重训，新闻语义没有暗中变成新的球员惩罚系数 |
| LLM | 阅读原文与原值，区分事实、条件解释和未知，解释哪些信息可能新增、哪些可能重复计入 | 本轮没有LLM微调，也没有用历史回看冒充真实赛前预测 |
| 助手综合 | 将新闻、近期参与及模型已用窗口联系起来，保留分歧和信息缺口 | 尚不能从文字自动给出可靠的净进球／胜率修正，也不机械平均产生新概率 |

下一步在新的真实赛前分析中复用这套单场阅读接口：统计先给完整H／D／A，LLM逐条解释来源信息与统计窗口的关系，助手给出取舍依据，三项概率保持独立可追踪。实际应用需要对应当时的最新来源；2022–26历史快照本身不能当今天的球队状态。若要进一步估计人员相对替代者的作用或改变概率源头，需要明确的联合结构及讨论，不能靠此次文本整理暗中完成。

本轮另外核查了两份非英超公开人员档案，发现它们可用于后验解释或理想信息研究，但缺少可靠的逐条历史公告时点。当前不把事后结束日期、实际首发／出场标签回填成历史赛前事实。它们的可借鉴部分、真实字段与局限单列在[来源盘点](G:/Codex/football-prediction-2026-10-22/outputs/人员信息语义接入_20261028/非英超可用性来源盘点.md)，没有因此否定人员信息方向。

独立复核覆盖8,753场、111,608条当前球员引用、3,004个有来源队侧及459个快照，重现三例机制选择，并对三场所选球队的35／46／52名球员独立重算窗口分钟和当前／旧源文本。发现的全历史目录元数据进入LLM视图问题已修正：全历史次数、最晚观察跨度仍保存在来源目录，单场LLM输入仅含本场引用文字及各自来源。单场渲染器另补齐旧名单独有新闻ID的本地语义引用；目标标签、目标实际首发与分钟不进入计算、选择或输出。

本轮只测量已有原始记录可支持什么，没有下载、训练或拟合状态修正系数，也没有查询当前比赛赛果。独立整场比分只核对进球记账，未填入任何射门前状态。

共处理 760 场、20,402 条射门，解析失败 0 场。2023/24 与 2024/25 英超各 380 场。逐场覆盖见[射门比分状态覆盖](G:/Codex/football-prediction-2026-10-22/outputs/平局条件信息定位_20261027/射门比分状态覆盖.json)，逐射门记录见[历史逐射门比分状态](G:/Codex/football-prediction-2026-10-22/outputs/平局条件信息定位_20261027/历史逐射门比分状态.json.gz)。

## 原字段语义与实际冲突

- h_goals/a_goals 在全部 20,402 条记录中都与独立终场比分相同，不能用作射门前比分。
- 84 条 OwnGoal 必须记给 h_a 的对侧。按该规则统计 Goal/OwnGoal，760/760 场与独立终场比分一致；这只能支持本批次记账完整性，不证明每条事件时刻正确。
- 103 场在原同侧数组中出现分钟回退，共 107 次，提示半场补时与下半场分钟重叠的实际风险。原字段没有 period 或秒，不能按 minute、id 或源数组顺序构造全场时间线。
- 3 场出现同一 minute 标签的多个进球；483 条射门与另一个进球共享 minute 标签。共享标签不一定发生在同一个实际分钟，尤其跨半场时；不能用 id 的大小确定先后。
- 同场重复 id 会由解析器明确报错；本次实际解析失败为 0，跨场重复 id 为 0。

## 保守恢复范围

只解释 minute<45 的 8,752 条射门，占全部 42.90%。这一可用性仍依赖来源采用全场累计分钟、下半场不会重新从 0 起计的语义。它不是官方 period 的替代，不能当作完整全场或真实时间暴露复现。

在该范围内，8,577 条具有唯一射前比分，175 条保留同分钟可能比分集合。集合由更早分钟已发生的 Goal/OwnGoal 加上同分钟其他进球的所有可能前缀计数构成，当前 Goal/OwnGoal 自身不计入射前。

从本方角度看，8,625 条可唯一判定领先／持平／落后，另有 127 条状态仍有歧义。比分不唯一但所有可能比分都处于同一领先或落后状态时，保留“比分未知、状态已知”的区别。

其余 11,650 条射门均标为半场未识别／时钟重叠未知，即使分钟很大也不凭经验恢复。1295 条 minute>90 的记录不用于估计实际补时长度或终场暴露。未知字段为 null，绝不当作 0:0 或持平。

## 学到什么与仍缺什么

已得到一个可复用的研究组件，能安全处理乌龙归属、自身进球排除、同分钟状态集合以及“比分不唯一但本方状态唯一”。这确认了历史源可以提供一部分条件信息，也量化了缺失 period 带来的覆盖限制。

原始每射门 xG 原样保留，没有相加、补射链聚合或替代来源 NPxG；不能把本测量的射门覆盖当成 xG 覆盖或整场攻防强度。历史文件的最初发布时间和修订仍未知。要恢复完整比分状态，需要独立可靠的半场／阶段标识或更精确事件时钟；本轮没有用 ID、数组经验顺序或最终比分代替这些信息。

本轮结果是数据可用性与语义测量，不是平局预测提升的证据，没有据此产生新的模型系数或更新现有预测。

# 历史首发数据实测与下一步

本轮将优化重点从融合权重转向球员信息，完成了真实数据试样、跨源测量与可复用读取模块。**尚未训练新球员模型，也没有获得新的预测准确率。** 主客分配对照已结束且不采用；当前赛果复核仍暂停。

## 已经实际接通的数据

使用既存、已精确对应的Football-Data／Understat历史比赛，从2023/24与2024/25五联赛各选择同一锚点球队的前两场符合条件比赛，共20场。选择规则只依赖球队、日期与既有资料可对应性，不按赛果或模型误差选取。五支锚点球队是Arsenal、Augsburg、Alaves、Atalanta与Brest。

20个历史公开接口请求均返回HTTP 200，原始响应和接入记录保存在G盘。此样本覆盖40个球队名单、623条实际参赛球员记录。它不是五联赛完整首发数据库。

| 实测项目 | 结果 |
|---|---:|
| 每队恰好11条非Sub记录 | 40／40队次 |
| 首发席位／替补参赛记录 | 440／183 |
| 每队参赛球员记录数 | 13—16 |
| 独特名单行ID／球员ID | 623／434 |
| 跨场重复球员ID | 103个，样本内姓名冲突0 |
| 同一锚点球队跨季共同球员ID | 合计50个，样本内姓名冲突0 |
| 非零换人关联 | 366条，均同队且互反 |
| 射门对应球员 | 531／531，样本内身份及所属侧冲突0 |

跨季共同ID分别为Arsenal 12、Augsburg 9、Alaves 9、Atalanta 9、Brest 11。这支持进一步研究同源跨季身份延续，但不证明整个供应商历史的ID均永久稳定，也不能据此推算全季未知球员比例。

## 首发标签的独立测量

直接使用原始`position`的场上位置与`Sub`标记，未用出场分钟或换人路径猜首发。再与已有IMPECT显式`startingPositions`核对2023-08-19 Augsburg—M'gladbach及2023-08-27 Bayern—Augsburg。

两场合计44个首发席位中，36个姓名原文一致，5个仅格式或变音符差异，3个需要显式人工姓名对应：Nathan N'Goumou Minpol／Nathan Ngoumou、Kim Min-Jae／Min-jae Kim、Dayotchanculle Upamecano／Dayot Upamecano。接受这三项同场同队的人工对应后，两场均为22／22，没有无法对应的首发。三项人工证据没有外部身份资料进一步确认，不建立跨供应商球员ID表。

**首发身份可对应，不表示位置角色等价。** 两场Augsburg的Demirovic／Vargas在Understat为AMC，在IMPECT为左右边锋；不能把旧角色映射直接搬来。IMPECT的`currentSquadId`也不能当历史队伍归属，本次只使用该场队伍名单。

## 可复用读取模块与实跑

新增`understat_rosters.extract_starting_xi(payload, identity)`。调用方须提供既有精确联结的比赛日期、主客队及比赛ID；读取器只读取`rosters`区块，其中没有比赛日期与球队名称。原始响应的射门区块另有日期、球队名与比赛ID，可用于资料身份测量，但本函数不读取该区块，也不声称独立验证了这些外部信息。

输出包括比赛身份、带Understat命名空间的首发球员ID、来源与“历史首次公布时间未知”说明。使用`player_id`作为球员身份，不能使用当场名单行`id`或字典键。读取模块不输出同场进球、xG、射门、出场分钟、换人或牌数，也不把整场位置标记输出为赛前战术特征。

79项聚焦测试通过，包含20场真实样本，以及ID混淆、重复球员、错误主客侧／队伍、未知位置码、10或12名首发、90分钟替补、位置排序码15／16和赛后字段变化等具体失败情景。20场已实际转为440个首发身份观察。**这些是解析与防止信息混入的验证，不是预测效果验证。**

## 当前不能据此判断的内容

- 历史首发首次公布时间未知，只能支持“首发已知条件下”的日期级历史研究，不能称提前一天已知首发。
- 名单反映实际参赛者，未保证包含未使用替补；未出现的球员不能直接标为伤停，也不能据此得到完整可用阵容。
- 分钟是整数，样本有27组“90分钟＋1分钟”的换人配对，不能重建精确在场秒数；还有一次替补再次被换下，不能假定被换下者都是首发。
- 当前伤停、预计首发、教练计划、赛事重视程度、欧战轮换和临时决定仍缺具有历史可用时间的信息。不得用赛后实际轮换反推赛前动机。
- 本次只有两个赛季季初的20场，未量化完整后季覆盖率及转会后的可迁移性。

## 下一步如何直指预测

旧球员路线已经做过在场时段、开场11人、分层收缩与未知球员不确定性对照，尚无稳定跨样本增益，不能称本轮发现了全新的球员算法。现代同源跨季资料能新增的检验，是更早赛季积累身份后，在完整后季观察首发变化的增量，而非换数据名再调同一批参数。

建议下一项核心研究以现有球队进球率为比较起点，检验开场11人能否提供额外的相对攻防信息；不把同场分钟及实际换人作为输入。纯球队／xG线与加首发线必须使用相同比赛、可用时间与评分规则；已知、未知球员及缺名单均须报告，不能只留下资料齐全或结果好的比赛。原球员线的损失尺度和惩罚不同于现主线，必须先讲清对照关系，不能直接把两份历史评分相减当增益。

是否新增这项首发增量结构已向用户发起讨论，本轮不提前训练。若推进，先固定小规模可解释结构及既有设置，较早季学习、较晚季检验，避免参数网格。未知球员不按已知零影响处理；未经验证，不修订现有预测、不调整市场／LLM联合权重，也不直接引入神经网络。
